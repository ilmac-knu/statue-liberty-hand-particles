# 손짓으로 만드는 자유의 여신상

**Hand-Tracked 3D Particle Animation** — 손동작 인식과 3D 입자 애니메이션 실습.

## 업로드할 파일

- `index.html` — 체험 페이지
- `statue_of_liberty_1.glb` — **기존에 확보한 자유의 여신상 모델을 이 이름으로 같은 폴더에 업로드하세요.** (별도 제공되지 않음)

GLB가 없으면 간단한 대체 형상이 표시되며, 정확한 자유의 여신상 입자 모델을 보려면 GLB 파일이 필요합니다.

## GitHub Pages 배포

1. 새 공개 저장소 `statue-liberty-hand-particles`를 만듭니다.
2. `index.html`, `statue_of_liberty_1.glb`, `README.md`를 저장소 최상위 폴더에 올립니다.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.
4. 잠시 후 `https://ilmac-knu.github.io/statue-liberty-hand-particles/`에서 접속합니다.

## 조작

- **손 추적 시작**: 전면 카메라 권한을 허용합니다. 인터넷 연결이 필요합니다.
- **손바닥 펼치기**: 3D 입자가 흩어집니다.
- **주먹 쥐기**: 3D 입자가 원래 모델로 모입니다.
- **손 좌우 움직이기**: 3D 입자 조형물의 방향이 달라집니다.
- 카메라가 동작하지 않으면 화면 아래 **입자 분해 / 다시 결합** 버튼으로 체험합니다.

## 기술 구성

- Three.js + MeshSurfaceSampler: GLB 표면을 3D 입자 점으로 변환
- MediaPipe Hands: 웹캠 손 관절 좌표 및 제스처의 간단한 휴리스틱 판정
- JavaScript 입자 애니메이션: 분해, 결합, 이동

## 참고 및 한계

- 초기 로딩 시 CDN에서 라이브러리를 내려받으므로 인터넷 연결이 필요합니다.
- 카메라는 브라우저에서 손동작 분석에 사용되며 본 코드에는 영상 전송/저장 기능이 없습니다.
- 스마트폰 기종, 조명, 카메라 권한, 브라우저에 따라 손 인식률이 달라집니다.
- 손을 펴거나 쥐는 동작의 판정은 휴리스틱으로 구현했으므로 실제 기기에서 조정이 필요할 수 있습니다.
- 화면에 보이는 것은 3D 파티클 애니메이션이며, 화면 밖으로 실제 물체가 돌출하는 입체 영상은 아닙니다.
